# 阶段一性能调优记录

基线为 `ae4dff1`：该版本包含前三阶段，但本轮对照关闭推测解码和量化，聚焦第一阶段的统一调度、分块 Prefill 和混合执行。基线数据与此前性能对照均已保留在 `docs/性能对照`。

1. [调优 01：混合批次 Prefill 预算](01-混合批次预算/README.md)：尝试在有 Decode 时限制 Prefill 为 128 token；六轮数据表明吞吐和 TTFT 明显退化而 ITL P95 未改善，**否决**。记录包含实验补丁和原始结果，生产代码不保留该实验开关。
2. [混合执行剖析](02-混合执行分析/README.md)：对一次 512-token 混合 batch 做 CPU profiler，记录逐层调用数量；当前环境 CUPTI 不可用，没有 GPU kernel 计时。
3. [调优 02：可选混合 CUDA Graph 复用](03-混合图复用/README.md)：以重复形状为目标，在支持条件下缓存图，其余路径保留原行为。样本中的暖态长输入吞吐提高 64.93%，错峰吞吐提高 40.10%；首次形状捕获更慢，因此开关默认关闭。报告保留冷态和暖态数据、显存、正确性测试及限制。

每项收益均限于其报告所述工作负载、硬件和测量口径；共享 GPU 和样本量使小幅变化不能认定为稳定收益。请先阅读各报告中的边界与复现方法，再决定是否启用。
